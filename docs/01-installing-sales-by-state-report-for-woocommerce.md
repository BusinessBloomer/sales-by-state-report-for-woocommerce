# Installing Sales by State Report for WooCommerce

Sales by State Report for WooCommerce is free, and it installs the same way as any other plugin. It requires WooCommerce to already be active, since it reads its report straight from your store's own order data.

## Install and activate

From your WordPress dashboard, go to Plugins, then Add New Plugin, and search for "Sales by State Report for WooCommerce". Click Install, then Activate. If you'd rather install it manually, download the zip from WordPress.org and upload it under Plugins, Add New Plugin, Upload Plugin.

![screenshot](01-install-activate.jpg)

## What happens after activation

There's nothing to configure. As soon as the plugin is active, it starts reading your existing orders in the background so the report is ready when you open it. On a store with a lot of order history, this can take a moment, and the report page will show a progress bar until it's done.

If you're setting this up on a brand new store with no orders yet, the report will simply be empty until your first orders come in, and it fills in automatically from there.
