# Where to Find Your Sales by State Report

The report lives in a different spot depending on whether WooCommerce Analytics is turned on, but it looks and works exactly the same either way.

## With Analytics enabled

If you use WooCommerce Analytics, go to Analytics, then Sales by State. It sits right alongside Revenue and Orders, built from the same components, so it fits in as if WooCommerce shipped it.

## With Analytics disabled

If Analytics is off, or your store doesn't use it, go to WooCommerce, then Sales by State instead. It's the same report, same filters, same table, just reached from a plain WooCommerce submenu rather than the Analytics section.

![screenshot](02-report-default.jpg)

Either way, you don't need to decide anything. The plugin checks whether Analytics is available and puts the report wherever it belongs, automatically.
